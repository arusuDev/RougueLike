# ダンジョンポイント（DP）システム設計書

## 概要

本ドキュメントは、ダンジョン選択システムとDP（ダンジョンポイント）によるスキルツリー強化システムの設計仕様を定義する。

---

## 1. ゲームフロー

```
タイトル画面
    ↓
ダンジョン選択画面
    ↓
ダンジョンプレイ（毎回Lv1スタート + スキルツリー補正）
    ↓
┌─────────────┬─────────────┐
│   クリア     │   死亡      │
│             │             │
│ リザルト画面  │ ゲームオーバー │
│ DP獲得       │ アイテム/EXP │
│             │   消失      │
└─────────────┴─────────────┘
    ↓
タイトル or DP振り分け画面
```

## 2. ダンジョン定義

### 2.1 初期ダンジョン一覧

| ダンジョン名 | 階層数 | 難易度 | 説明 |
|------------|-------|--------|------|
| 始まりの洞窟 | 6階層 | ★☆☆☆☆ | 初心者向け。スキルツリー未解放でもクリア可能 |
| 東の大灯台 | 10階層 | ★★★☆☆ | 中級者向け。ある程度のDP投資が必要 |
| 封印された教会 | 14階層 | ★★★★★ | 上級者向け。十分なスキルツリー解放が必須 |

### 2.2 ダンジョン選択仕様

- **初期状態**: 全3ダンジョンが選択可能
- **将来対応**: 新規ダンジョン追加時はアンロック条件を設定可能（現時点では未実装）
- **難易度表示**: 各ダンジョンに推奨DP量や難易度を表示

### 2.3 ダンジョンデータ構造

```typescript
interface DungeonDefinition {
    id: string;                    // 一意のID
    name: string;                  // 表示名
    description: string;           // 説明文
    floors: number;                // 階層数
    difficulty: 1 | 2 | 3 | 4 | 5; // 難易度（星の数）
    recommendedDP: number;         // 推奨DP投資量
    enemyScaling: number;          // 敵ステータス倍率
    expMultiplier: number;         // 経験値倍率
    unlocked: boolean;             // 解放済みか（将来用）
}
```

## 3. クリア条件とリザルト

### 3.1 クリア条件

- **最終階層で階段を使用して脱出**することでクリアとなる
- 最終階層には特別な「脱出階段」を配置

### 3.2 死亡時の処理

- 所持アイテムは**全て消失**
- 獲得経験値は**全て消失**
- DPは獲得できない
- ゲームオーバー画面を表示

### 3.3 リザルト画面

クリア時に以下の情報を表示：

```
┌─────────────────────────────────┐
│       ダンジョンクリア！          │
│                                 │
│  「始まりの洞窟」 クリア          │
│                                 │
│  ─────────────────────────────  │
│  獲得経験値:           1,250 EXP │
│  所持アイテム:                   │
│    回復薬 x3            15 DP    │
│    炎の巻物 x1          20 DP    │
│  ─────────────────────────────  │
│  経験値ボーナス:       125 DP    │
│  アイテムボーナス:      35 DP    │
│  ─────────────────────────────  │

│                                 │
│  [タイトルへ]  [スキルツリーへ]    │
└─────────────────────────────────┘
```

## 4. DP（ダンジョンポイント）システム

### 4.1 DP獲得計算式

```
合計DP = 経験値DP + アイテムDP

経験値DP = 獲得経験値 ÷ 10（端数切り捨て）
アイテムDP = Σ(所持アイテムのDP価値)
```

### 4.2 アイテムDP価値（暫定）

| アイテム種類 | DP価値 | 備考 |
|------------|--------|------|
| 回復薬 | 5 DP | 最も基本的なアイテム |
| 炎の巻物 | 20 DP | 攻撃系アイテム |
| （将来追加枠） | - | 今後拡張 |

### 4.3 ダンジョン別経験値倍率（暫定）

| ダンジョン | 経験値倍率 | 説明 |
|-----------|-----------|------|
| 始まりの洞窟 | x1.0 | 基準値 |
| 東の大灯台 | x1.5 | 1.5倍の経験値 |
| 封印された教会 | x2.0 | 2倍の経験値 |

## 5. スキルツリーシステム

### 5.1 概要

- **分岐ツリー形式**: 複数のルートから選択して強化
- **初期ステータス強化**: HP、攻撃力、防御力などの初期値を上昇
- **パッシブスキル**: 3段階目、5段階目などで特殊効果を解放

### 5.2 スキルツリー構造（分岐・再分岐対応）

```
                         [スタート]
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
         [HP強化Ⅰ]      [攻撃強化Ⅰ]     [防御強化Ⅰ]
         HP+5           ATK+2          DEF+2
         10DP           10DP           10DP
              │               │               │
              ▼               ▼               ▼
         [HP強化Ⅱ]      [攻撃強化Ⅱ]     [防御強化Ⅱ]
         HP+10          ATK+3          DEF+3
         25DP           25DP           25DP
              │               │               │
       ┌──────┴──────┐  ┌──────┴──────┐  ┌──────┴──────┐
       ▼             ▼  ▼             ▼  ▼             ▼
   [生命力]      [再生]  [会心の目]  [猛攻]  [鉄壁]    [反撃]
   ★パッシブ   ★パッシブ ★パッシブ ★パッシブ ★パッシブ ★パッシブ
   被ダメ時    ターン毎   クリティカル 攻撃時   被ダメ    被ダメ時
   HP1%回復   HP1回復   率+10%    ATK+1   -10%     反撃30%
   50DP       50DP      50DP      50DP    50DP     50DP
       │             │  │             │  │             │
      ...           ... ...           ... ...           ...
```

**設計ポイント**:
- 各メインブランチ（HP/攻撃/防御）は独立して進行可能
- 3段階目以降で**サブブランチに分岐**（例: HP系 → 生命力 or 再生）
- サブブランチも更に深く（5段階目以降）分岐可能な構造
- 複数ブランチの並行解放も可能（DP次第）

### 5.3 スキルノードのデータ構造

```typescript
interface SkillNode {
    id: string;                    // 一意のID
    name: string;                  // スキル名
    description: string;           // 説明文
    cost: number;                  // 必要DP
    tier: number;                  // 段階（1, 2, 3...）
    type: 'stat' | 'passive';      // ステータス強化 or パッシブ
    prerequisites: string[];       // 前提スキルID
    effects: SkillEffect[];        // 効果一覧
    unlocked: boolean;             // 解放済みか
}

interface SkillEffect {
    type: 'hp' | 'attack' | 'defense' | 'passive';
    value: number;                 // 上昇値（%の場合もある）
    passiveId?: string;            // パッシブの場合のID
}
```

### 5.4 パッシブスキル案

| パッシブ名 | 効果 | 解放段階 |
|-----------|------|---------|
| 生命力 | 被ダメージ時、最大HPの1%回復 | 3段階目 |
| 会心の目 | クリティカル率+10% | 3段階目 |
| 鉄壁 | 被ダメージ-10% | 3段階目 |
| （追加枠） | - | 5段階目以降 |

## 6. データ永続化（ローカルストレージ）

### 6.1 保存データ構造

```typescript
interface SaveData {
    version: number;               // セーブデータバージョン
    totalDP: number;               // 累計獲得DP
    currentDP: number;             // 使用可能DP
    unlockedSkills: string[];      // 解放済みスキルID一覧
    dungeonProgress: {             // ダンジョン進捗
        [dungeonId: string]: {
            cleared: boolean;      // クリア済みか
            bestTime?: number;     // 最速クリアタイム（将来用）
        };
    };
    statistics: {                  // 統計情報（オプション）
        totalClears: number;
        totalDeaths: number;
        totalPlayTime: number;
    };
}
```

### 6.2 ローカルストレージキー

```
rougulike_save_data
```

### 6.3 データクリア機能

- 設定画面またはタイトル画面から「データ初期化」を実行可能
- 確認ダイアログを表示後、全データを削除
